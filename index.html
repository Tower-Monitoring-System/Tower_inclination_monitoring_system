SYSTEM ARCHITECTURE

Demo Concept

Each monitoring node can use an ESP32, MPU6050 tilt sensor and LoRa 433 MHz module. Sensor data is transmitted to a master station and displayed on this web dashboard.

MPU6050 → ESP32 Node → LoRa 433 MHz → Gateway → Web Dashboard

DEMO NOTES

How this sample works

  • No backend is required.
  • Sensor values are simulated in JavaScript.
  • The chart is drawn using HTML Canvas.
  • It can be deployed directly on GitHub Pages.
  • Later, you can replace mock data with MQTT/API data.
